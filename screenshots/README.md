# Скриншоты

Планируемые кадры для страницы-кейса и видео:

1. Запуск демо в консоли: маршруты и метраж кабеля.
2. Таблица заполнения лотков с перегруженным участком `T08`.
3. CSV-файлы `cable-stock.csv` и `tray-fill.csv`, открытые в Excel.
4. (Для приватной версии) AutoCAD с загруженным bundle и результатом `CABLE-TRACE`.

Скриншоты добавляются после записи демо. Данные на кадрах — только синтетические.
