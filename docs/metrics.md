## Что именно измерялось

- **Паритет длин** — сумма длин кабелей по 40 задачам на эталонном чертеже.
  3809 из 3809 значений совпали с исходной версией; расхождений `far` — 0.
- **Задачи** — отчёт `CABLE-TRACE` по 117 задачам: без замечаний, потерянных
  приёмников нет.
- **Автотесты** — xUnit-тесты чистой логики, запускаются без AutoCAD.
  Проверено командой `dotnet test` в приватном репозитории.
- **Golden-регрессия** — 19 наборов на headless AutoCAD (`accoreconsole`):
  СКС, камеры, указатели. Baseline хранится в git, дифф после каждой правки.
- **Скорость** — время `CABLE-TRACE` на копии эталонного чертежа: 6,2 с у новой
  версии против 18,2 с у исходной.

## Почему это важно

Для CAD-плагина «работает» — недостаточно. Нужно, чтобы результат совпадал с
тем, что пользователи уже видели годами: длины, схемы, спецификации, чертежи.
Поэтому главный показатель проекта — не количество строк, а паритет с исходной
версией, подтверждённый эталоном и регрессией.
